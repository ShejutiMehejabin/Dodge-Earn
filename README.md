Dodge&Earn

A 2D game developed using C++ and the Raylib multimedia library.

Project Structure

- "main.cpp" – Main source code.
- "assets/" – Game resources.
- "raylib/" – Raylib library files.
- "build.bat" – Windows build script.
- "app.exe" – Compiled game executable (if included).

Installation & Setup

1. Download the project ZIP file or clone this repository.
2. Extract the ZIP file if downloaded.
3. Open the project folder.

How to Build

Run "build.bat" to compile the game.

How to Run

Run "app.exe" to launch the game.

Technologies Used

- C++
- Raylib

Note

The project requires the complete set of files and dependencies to build successfully. The "main.cpp" file alone is not sufficient.
